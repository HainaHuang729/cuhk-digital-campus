## 实际性能采样

同一台 RTX 4090，3秒绘制帧窗口。FPS受本机160Hz刷新率限制，以下是指定视角样本，不能代表所有显卡或实际手机。

| 项目 | 桌面中央校园 | 手机尺寸图书馆视角 |
|---|---:|---:|
| CSS视口 | 1280×720 | 390×844 |
| DPR / 画布 | 1.5 / 1920×1080 | 1 / 390×844 |
| 画质 / AO | High / 开 | Low / 关 |
| 实际绘制FPS | 160 | 30（主动限帧） |
| 帧间隔p95 | 6.3 ms | 37.6 ms |
| draw calls（含附加pass） | 1,073 | 145 |
| triangles（含附加pass） | 7,726,331 | 2,535,962 |
| 细节区域 | 5 | 2 |
| 当前压缩模型量 | 27.46 MiB | 26.88 MiB |
| 几何缓冲估算 | 94.8 MiB | 93.8 MiB |
| JS heap样本 | 137.7 MiB | 115.8 MiB |

手机一列仍在桌面显卡运行，只验证布局、Low设置和30FPS调度，未完成真实手机／集显性能测量。GPU显存不可直接取得；几何估算、JS heap和压缩资源大小不是显存。

原版同机中央校园环绕基线159.3FPS。新版近景AO增加额外绘制pass，不能仅比较一个draw call数字判断效率。当前样本未出现明显帧率下降；不同视角、加载瞬间和设备需分别评估。机器可读样本：`../artifacts/cuhk/audits/digital_campus/desktop-final-metrics.json`、`mobile-final-metrics.json`。

实际切换High→Medium→Low后，细节区域5→3→2；AO关闭、DPR降至1.25／1，旧区域释放。对应稳定样本约159.7／160FPS，手动画质未被自动覆盖。早期后台预览降至约1FPS，属于浏览器节流，未用于设备结论；自动降档现在排除无焦点、静止按需绘制、加载及飞行状态。
