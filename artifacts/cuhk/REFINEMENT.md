# CUHK 精细视觉模型

使用 `CUHK_refined.blend`。默认相机为校园核心区近景；另外保留东南鸟瞰相机和正北俯视相机。高清成图为 `CUHK_refined_closeup.png`（3000×2200）和 `CUHK_refined_overview.png`（3200×2800）。

本版本是在原地理体量模型上增加视觉细节，**不是按建筑实测图完成的建筑级复原**。原始高度来源属性、OSM ID、平面轮廓和原始场景均保留。

## 已增加的内容

- 195 栋校内建筑增加立面细节：36,808 组窗、窗台、玻璃与窗框、8,731 段层间线、2,285 段女儿墙、178 个示意入口雨棚，以及 246 个屋顶设备。
- 181 段道路边缘、54 段道路的中心虚线（914 段虚线）、157 盏示意路灯。
- 3 个足球场及6个球门、7 个篮球场、9 个网球场、2 条跑道分道线及1处泳池泳道。布局依据原 OSM 平面，内部线位与附属设施采用通用示意。
- 1,374 株可编辑树木实例。树点和树列位置、林地区域来自 2026-09-08 获取的 OSM 标注；林地中的单株位置与所有树形、高度为示意生成，避开建筑、道路和运动场。树木共享8种网格以控制文件体积。
- 更柔和的地表与水面材质、建筑边缘高光及适合近看的灯光。

## 地形与精度边界

基础来源仍是香港地政总署5米 DTM 与 OSM 平面数据。原 DTM 可能含植被高度；建筑高度依然只有5处采用高度标注、60处按楼层换算、140处为用途估算。本次外观细节不会提高这些数据的测量精度。

精细版另存了一份显示地形 `terrain_refined_display.npz`，在原建筑基底高程附近、以及运动场/水体轮廓范围内实施**示意整平**，用于改善地基和场地表现；边缘作有限过渡。它不是实测台地、挡土墙或土方设计。最大局部高程调整约26.3米，原始地形 `terrain.npz` 与原始 Blender 场景未改变。整平记录见 `platforms.json`。

道路和新增场地构件重新采样贴合此显示地形。地形三角面和采样采用同一对角线规则，路面增加细分，以减少陡坡处穿插。桥梁、隧道、挡土墙、多标高入口和边坡仍为简化处理。坡面上局部道路形态仍受地形数据和建模近似限制。

外墙与屋顶材质、窗数和窗位、屋顶设备、灯杆、入口雨棚和树冠均为示意设计，不应据此判断校园真实建筑细节。

## 可编辑结构与复现

- 原 `02 Campus buildings`、`03 Context buildings` 内370个建筑源网格及主高度未改动；校内建筑增加可关闭的微小倒角修改器。
- `07 Building details / illustrative` 为逐栋合并的建筑细节网格，可单独隐藏/编辑。
- `08 Site details` 为按材质合并的道路与运动设施细节。
- `09 Mapped vegetation / illustrative crowns` 为树木实例。
- 统计见 `refinement_stats.json`。

`detail_buildings.py` 与 `detail_site.py` 可独立调用；`prepare_vegetation.py` 使用原始 OSM 缓存及已有 GIS 依赖生成植被点与显示地形。`refine_cuhk.py` 从彩色版载入，添加细节，保存精细版并渲染。运行方式：

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' --background --python-exit-code 1 --python refine_cuhk.py
```

验证包含原建筑顶点数量与对象数不变、建筑细节顶点有限、运动场标签及计数合理、地形/场地使用同一高度采样，以及实际近景和鸟瞰渲染检查。地理来源与许可沿用 [README.md](README.md) 中的地政总署与 OpenStreetMap 署名。
