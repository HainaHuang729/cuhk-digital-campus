三张均来自现有 Three.js 场景，使用同一机位 `[400,310,740]`、目标 `[228,12,430]`、43° 透视视野和 16:30 光照，不是 AI 改绘。动植物、行人动画可能处于不同帧。

验证：26 项测试通过，生产构建通过；浏览器逐个预设切换、导出截图，未报告渲染错误。保持原有大于 500 kB 的构建包提醒。当前用于选定视觉方向，尚未逐栋精修，也未验证手机真机性能。
