# 逸夫科学大楼：政府三维参考样板

获取与核查：2026-09-28。范围仅为 **160 × 115 米**，香港1980方格 E839400–839560、N830995–831110。原 Blender 文件和正式校园网格没有改动；参考层默认关闭，首次启用才下载 656,009 字节的本地样板。无需在线请求整香港 3D Tiles。

建筑原始获取仅沿相交包围盒读取4个目录JSON和14个叶片，合计434,473字节；完整局部查询包含邻楼，发布样板只保留匹配成功的一栋。先合并每个官方 batch 的三角形水平投影，再与现有 OSM 轮廓计算交并比。本楼最佳0.8531，次高0.0126；匹配不依赖最近名称猜测。官方未给中大楼名，名称关联是本项目几何核对的结果。

官方资料：[LandsD 三维数据API](https://portal.csdi.gov.hk/csdi-webpage/apidoc/3d-spatial-data-api)、[三维地图与3D-BIT产品](https://www.landsd.gov.hk/en/survey-mapping/mapping/3d-mapping.html)、[CEDD LiDAR](https://www.ginfo.cedd.gov.hk/geoopendata/eng/LIDAR.aspx)、[2020元数据](https://www.ginfo.cedd.gov.hk/geoopendata/Data/LiDAR/2020%20LiDAR.xml)。建筑/基础设施API提供全港覆盖WGS84 3D Tiles；生产在线使用应按文档申请免费key。本轮离线获取使用文档公开示例key，没有用户私有凭据。3D-BIT传统分幅格式包含3ds/FBX/Max/VRML，不等同完整BIM，也不与本样板带纹理独立模型混称。

## 坐标链与没有解决的垂直语义

1. CEDD：读取GeoTIFF像元中心 E/N/H，水平EPSG:2326，垂直HKPD（EPSG:5738）。Three世界坐标严格为 `[E−839400, H, −(N−831150)]`，单位米，无夸张比例。
2. LandsD叶片：完整保留 glTF 节点变换，再将 glTF Y-up 转成3D Tiles Z-up，即 `[x,-z,y]`；应用根ECEF平移 `[-2413000,5380000,2420000]`。之后以PROJ作ECEF EPSG:4978 → WGS84经纬度/椭球高 EPSG:4979 → EPSG:2326平面坐标。没有在全球ECEF大数上使用float32减原点。
3. WGS84经纬度不能直接以经纬差当米；用PROJ官方定义的香港1980转换，五个点与地政总署坐标API的XY最大差约0.0054米。这只是两种转换实现一致性，不是建筑测量精度。
4. **椭球高不能直接写成HKPD。** 本轮调用[政府坐标转换API](https://www.geodetic.gov.hk/en/gi/transformation.htm)取得样板四角“HKPD−椭球高”，在这200米范围拟合 `ΔH = −0.000030×localEast + 0.000025×localNorth + 2.8034` 米。独立中心检查残差0.0005米。平面仅作小区域数据转换，禁止外推为香港通用大地水准面。
5. 但建筑API页面只声明“WGS84”，没有明确说明源模型高程如何写入ECEF。按规范将ECEF高度理解为椭球高，再作上述转换，参考平顶为114.40米；**若源文件在构造ECEF时直接使用HKPD数值，正确解释可能是111.60米。** 后者与2020 DSM吻合只是线索，不能证明源语义。因此默认显示规范换算版本，另提供“源高程诊断”切换，两个版本都明确待核，不选择最像现有模型的版本冒充正确答案。

所有控制点输入、官方API原始结果、转换系数、源叶片地址见 [source-and-coordinate.json](source-and-coordinate.json)。本地比例1，Blender→Three旋转X=-90°，本地附加平移0；绝对网格原点已在坐标公式中扣除。没有人工拖拽对齐或优化拟合楼体平移/旋转/尺度。高程模式切换只改变参考层，黄色主模型框保持原位。

## 几何差异与校准结论

| 项目 | 数据比较 | 结论 |
|---|---|---|
| 轮廓投影 | 现有OSM轮廓2599.98㎡；官方网格全部投影2416.49㎡；交并比85.31% | 大体方向和折线体量一致，边缘仍需局部核对；投影可能含悬挑，不是地籍基底面积 |
| 平面差异 | 官方投影质心向西1.58m、向南1.77m，合计2.37m；现有边界到参考边界距离中位1.29m，双向Hausdorff4.41m | 形状变化会移动质心，**不应把2.37m当作整栋平移参数**；优先核对凹口和长边，不整体挪楼 |
| 主屋顶 | 当前111.60mHKPD；DSM选择屋面平台中位111.607m，5–95%为111.466–111.743m | 与已经使用过的同源DSM基本一致，不能宣称新的独立验证；保留现有主屋顶 |
| 官方屋顶 | 统一平顶；规范垂直换算后114.40m，原始椭球数值111.60m；与现有主屋顶差约2.80m | 垂直语义未解决，禁止据此抬高当前屋顶2.8m |
| 两端设备和屋顶轮廓 | 当前两端约117.60m；官方样板只有统一平顶，不能表达这组细部 | 官方样板更粗，保留照片/DSM辅助的现有细资产，不用简单官方壳体覆盖 |
| 周边地形 | 排除本楼轮廓外3m及路面外3m后8901个样点，显示地形−DTM中位−0.118m，5–95%为−2.631至+1.692m，极值−9.314至+6.704m | 已人工整坡/建筑平台/年代差会造成差异。此统计包含邻楼平台，不能把所有差值当错误或整体恢复DTM |
| 道路衔接 | 大学道两段路面−DTM中位+0.091/+0.156m；中央道+0.109m；Clinic Road+0.166m | 在本轮抽样内与裸地高程大体接近，不建议推倒重修 |
| 路楼关系 | 中央道路面到当前轮廓1.73m，到官方投影4.10m；一段楼侧步道路面到当前轮廓0m、到官方投影1.77m | 是值得照片核对的边缘/入口候选；二维距离0可能是正常台阶或通道入口，不代表穿模已确认 |
| 需要复核的场地段 | 步道136995431中位−4.89m、台阶1349568930中位−4.14m，相对DTM偏低；Engineering Bridge中位+12.31m | 前两处应结合既有官方三维路径检查平台/阶梯标高。桥面高于DTM正常，不能强制贴地 |

道路统计在既有 `road_mesh_v3` 的实际三角形中心取样；本轮范围与后来运动场改路不相交。DTM采样取1米子集最近点，陡坡处存在约1米以内水平取样距离。统计检查地形参考差，不是对桥梁净空或路面拓扑重新出具验收。完整18条记录与筛选方法见 [geometry-differences.json](geometry-differences.json)。

本轮**不作新的主模型几何修正**。明确可做的是增加可回退参考和标记复核候选；目前没有足够依据证明应整体移动/拉高该楼，或将已整平路网重新贴裸地。后续经正射影像/现场尺寸确认后，建议在独立Blender文件中只修改确认的边缘顶点和对应平台，保留原始版本、变换记录、道路三角形哈希及前后同相机截图。

## 工具与复现

网页开发者面板提供参考显示、透明度、当前楼和参考楼边界框、样板聚焦、两种高程解释、对比图输出。青色为官方楼体、土色为DTM、橙点为DSM。未打开时不下载样板、不增加绘制；打开后3个数据绘制对象及2个可关闭的框，无额外纹理、阴影或实时网络流。

- `fetch_official_sample.py`：有空间筛选和请求/字节预算的离线官方数据获取。原始缓存位于 `C:/Users/Amadeus/.agent-reach/cuhk/calibration_20260928`。
- `build_reference.py`：读取原始缓存、确认坐标、匹配单楼、生成局部参考和差异报告；断言覆盖有限坐标、匹配唯一性、控制点、CRC及发布包体预算。
- `verify-reference.mjs`：实际加载Three参考模块，验证默认不请求、并发只请求一次、坐标/包体限制、两种高程可逆、透明度、边界框和释放。不需要WebGL上下文。

运行验证：`node artifacts/cuhk/calibration/verify-reference.mjs`。Python生成使用系统提供的Python3.12，依赖复用既有numpy、Pillow、Shapely和pyproj，没有新增网页依赖。

## 来源日期与使用限制

CEDD栅格原取得时间2026-09-22，本轮2026-09-28读取并复核；采集日期按2020元数据为2019-12-19至2020-02-01，另一目录摘要差一天，未自行消除。0.5米是采样间距，不是已验证的±0.5米精度。本轮未找到可直接用于该数据的定量垂直精度承诺。建筑取得时间2026-09-28，叶片未提供测量/摄影日期；`tilesetVersion1.2.3`不能当测量年份。

参考层署名香港特别行政区政府地政总署/土木工程拓展署，现有校园轮廓署名©OpenStreetMap contributors。政府数据许可允许按条款注明来源后使用和再分发，但数据按原样提供。本样板是独立裁切/转换与比较结果，**不是全校园官方精确重建，也不是测量认证**。在线来源和逐叶片地址均保留在附表中。
